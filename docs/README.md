# FPL DOF — documentation map

**FPL DOF** (Fantasy Premier League *Director of Football*) is a personal decision-support platform
for the 2026/27 season. A scheduled Python pipeline ingests data, forecasts expected points with
variance, solves a multi-gameweek MILP for squad, transfers and chips, and publishes static
artefacts that a React app on GitHub Pages reads. No server, no database, no bill.

Each fact has one home. Read the home; link to it from anywhere else; never copy it. How to write
and archive documents is in [`agents/documentation.md`](agents/documentation.md).
