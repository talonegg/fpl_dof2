Problem

The web client data layer exposes 16 shallow fetch functions and 6 module-scope caches with inconsistent error handling and missing offline warming.

Solution

Deepen into a unified DataStore module presenting a single query interface with transparent eager preloading, lazy memoisation, and offline warming.

  • contract validation runs across seam
