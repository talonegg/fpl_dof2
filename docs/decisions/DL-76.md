## DL-76 — C3: minutes_v2 promoted without a shadow window; captain by price and position until the model beats B0

**Status:** Accepted · **Date:** 2026-10-17 (recording a change shipped 2026-10-13 in `d6f35ad`) ·
**Decided by:** Owner · **Serves:** OBJ-1, OBJ-7, FR-10, FR-19

### Context

Commit `d6f35ad` (13 Oct) turned `forecast.discrimination.minutes_v2` on in the shipped
configuration and made `optimiser.captain_rule: price_position` the default, as one change called
"C3". Neither was recorded as a decision. minutes_v2 is a new model behaviour, so the
[E8 §5 bar](../planning/epics/E8-ongoing-in-season-monitoring.md#5-the-bar-for-changing-the-model-mid-season)
applies — held-out backtest improvement, six live shadow gameweeks, and an explanation in advance —
and the second condition was not met. The evidence the configuration cited,
`backtest/RESULTS_proposals.md`, was never committed and exists nowhere.

### Decision

1. **minutes_v2 stays on, as a deliberate exception to E8 §5's shadow condition.** The evidence is
   the decision-level backtest figure that survives in `config/defaults/forecast.yaml`: with the
   price-and-position captain, **+3.21 XI points per gameweek (interval 1.08 to 5.25) over 2023/24 to
   2025/26**. The explanation in advance is E10-S1's: rotation on fixture density, an injury-return
   ramp, and an availability haircut that hits starting harder than appearing. The six-gameweek
   shadow window was skipped because GW1–4 were decided without the tool (DL-69) and the gain was
   judged worth taking now. **The results file was never committed, so this evidence cannot be
   re-run as it stands** — that is a known weakness of this promotion, not a detail.
2. **Captain and vice are chosen by the B0 per-position price line** (`captain_rule:
   price_position`), not by the model's xP, because the model does not yet beat B0 at the head of the
   ranking (D-13, DL-21).
3. **Exit test for the captain rule.** Captaincy returns to the model (`captain_rule: model`) when
   the model card reports the model's **top-20 precision above B0's** — the same head-of-ranking
   measure DL-21 uses. Until then the rule stays, whatever a single gameweek suggests.

### Consequences

- The configuration comment cites this entry instead of the missing file.
- DP-08 (guiding) is departed from knowingly, which is what this entry records; it takes no
  `DP-WAIVER` marker (DL-75).
- If a later backtest contradicts the +3.21 figure, that is grounds to revert minutes_v2 without
  waiting for a further decision.
