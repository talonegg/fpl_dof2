## DL-95 — R1.4.0 is the UI redesign, in two drops; WEB-01, WEB-05 and WEB-06 wait

**Status:** Accepted · **Date:** 2026-10-24 · **Decided by:** Owner, on request ·
**Serves:** FR-23, FR-26, FR-27, FR-28, FR-31, FR-32, FR-33, FR-41, FR-42, NFR-03, NFR-14

### Context

R1.4.0 was planned as the independent web ([DL-86](DL-86.md)): decoupled deploys, the artefact
registry, UI flags and an experiments workflow, mostly plumbing. After R1.3.x the owner redesigned
the app around eight sections (Home, League, Models, Last gameweek, This gameweek, Scouting,
Analysis, Data health), several of which need data the pipeline does not publish. Chip set 1 needs a
plan by GW15 and expires at the GW19 deadline, and D-21 (chip timing) and D-34 (goalkeepers leading
the horizon xP) are open.

### Decision

1. **R1.4.0 is the UI redesign**, in two drops ([plan](../planning/epics/R1.4.0-ui-redesign.md)).
   Drop A re-lays the app on today's data with WEB-03, WEB-04 and D-29; Drop B adds the data and
   the views that read it, each an additive contract minor.
2. **Unmapped features keep a home.** The multi-week plan and chip calendar go under This gameweek
   as Plan ahead; the squad builder and compare players form a new Analysis section between
   Scouting and Data health; the season log is Last gameweek's "all gameweeks"; Settings is a gear
   in a global header that also carries the model selector and the run banner. Nothing is dropped.
3. **"Actual xPts" is underlying expected points**: the game's rules applied to FPL's own expected
   goals, assists and goals conceded and the minutes played, from `rules` config (ORC-12).
4. **The live season is replayed as if each model had played** from GW1, walk-forward, with
   gameweeks before a model went live labelled replayed, refreshed weekly by the backtest job
   (ORC-13).
5. **The league drill-down shows rivals' transfers, hits, chip and differentials**, fetched from
   public entry endpoints once a gameweek is Finished, capped at `squad_limit` (ORC-14).
6. **Odds are published per fixture with the margin removed**, beside the model's view, with no
   player odds (ORC-15).
7. **Each model publishes its options this gameweek** in the hindsight optimum's shape, within the
   300 s pipeline budget or in a job of its own (ORC-11).
8. **D-34 is rechecked and D-21 run as a declared experiment** in the existing weekly backtest,
   reporting before GW15.
9. **WEB-01 and WEB-06 move to a later release; WEB-05 waits for a first flag.**

### Consequences

- The app's paths change; every old path redirects.
- The 05 §7 independent release (decoupled deploys) and the experiments view are not delivered by
  R1.4.0.
- Drop B adds solves to the pipeline run and a replay to the weekly backtest; both are measured
  against their budgets before they ship.
