# Decisions

Architecture, product and process decisions for FPL DOF, one file per entry: `DL-nn.md` in this
folder. Each entry is immutable once accepted. To change one, write a new entry that names it as
superseded; the only edits an accepted entry takes are a re-pointed link and a one-line
`Superseded by DL-nn` note under its Status line (DL-74).

## Finding an entry

- Cited as `DL-47` anywhere: open [`DL-47.md`](DL-47.md). Do not search for it.
- By subject: scan the index below, or search this folder: `rg -l "risk dial" docs/decisions`.
- Entries DL-01 to DL-73 were one file, `docs/planning/00-decision-log.md`, until DL-74 split them
  with their text unchanged; the old file is gone (DL-75).

## Writing an entry

Record a decision **before** implementing it (CLAUDE.md, Conventions). Take the next number, write
`DL-nn.md` beginning:

```markdown
## DL-nn — <the decision, as a sentence>

**Status:** Proposed | Accepted · **Date:** YYYY-MM-DD · **Decided by:** <the owner, or an agent and why>
```

Then **Context**, **Decision** (numbered items), **Consequences**, and the requirement IDs it serves.
Keep it under 6 KB: measurements, test counts and run output go in the commit message or the model
card, which the entry names. Then run `python scripts/docs.py index` and
`python scripts/docs.py check`. CI fails when the index is stale or a cited `DL-nn` has no file.
