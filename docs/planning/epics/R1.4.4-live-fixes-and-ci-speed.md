first three items of a review of CI's test time.

## Stories

| ID | Story | Done when |
| --- | --- | --- |
| FIX-01 | Per-player rows only for finished gameweeks (FR-29) | `player_gameweek` holds no row for a gameweek FPL has not finished; a test fetches a summary mid-gameweek |
| FIX-02 | A not-live League row says whose figure it is (FR-32) | Its points are labelled as the gameweek in play's, from FPL's table |
| CI-01 | Shards balanced by measured time (NFR-09) | Modules are assigned to shards from recorded durations; the shards' totals are within a tenth of each other |
| CI-02 | The shard count set by measurement (NFR-09) | Two and three balanced shards timed; the faster kept and recorded |
| CI-03 | The slowest end-to-end tests trimmed (NFR-09) | The live gameweek's end-to-end tests repeat no pipeline run they do not assert on |
